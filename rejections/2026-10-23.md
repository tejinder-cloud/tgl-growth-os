# Rejected Proposals — 2026-10-23
**Do not re-propose these under any circumstances.**

## 1. Copying `config/` into `services/tgl-ops/config/`
- **Proposal:** Copy repository-level `config/` into `services/tgl-ops/config/` so Docker BuildKit finds local files during isolated service container builds.
- **Reviewer / Architect:** Tejinder Singh
- **Reason for Rejection:** Having two copies of `agents.yaml` (or any configuration file) violates the single-source-of-truth rule in `ORG.md §3`. Railway root-directory builds run in an isolated context; services must never duplicate shared configuration. Instead, services must fetch `config/agents.yaml` and `config/doors/*.yaml` dynamically from the repository's `main` branch via the GitHub Contents API using `GITHUB_TOKEN`, cached in-memory (e.g. 5 minutes), with a local-file fallback used strictly for local development.
