**Department:** marketing

## Accumulated Heuristics & Rules
- Thirty-second test is always run on mobile full-page screenshot (390px) first.
- Section rhythm notation: `T` (text-only), `V` (illustrative visual), `D` (decorative). Two consecutive `T`s or any `D` is an immediate `RETURN`.
- Tinted panels (`.tgl-panel`) at 24px desktop / 20px mobile replace hairline dividers. Top-left pill label uppercase.
- Mockups must appear as confident overlapping collage surfaces, never generic device frames or isolated screenshots.

## Pitfalls & Anti-Patterns Avoided
- Rejected simulated typing indicators, interactive demo toggles without real API endpoints, and hero micro-proof pills that duplicate subheads.
- Rejected price labels in the sticky mobile CTA pill (pricing belongs in FAQ).
- Banned stock photography and AI-generated portraits across all pages.
